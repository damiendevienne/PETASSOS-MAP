# Petassos UI wireframes

Open `index.html` for the screen catalog. The HTML files represent each window/state in the UI contract; `styles.css` is shared, and the genuine logo is loaded from `../img/petassos-logo.svg`.

The desktop Admin shell (`00-admin-shell-desktop.html`) is the canonical Places view. The duplicate `02-admin-places.html` entry was removed from the catalog; its old URL redirects to the shell.

The map background and markers are visual placeholders. Controls are not connected to a live map or data. The blue traveller location dot illustrates the state where location is available; it does not request or read device location.
